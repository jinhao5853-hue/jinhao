# 电气3班课表 · 2026-2027 学年第一学期

河南科技职业大学机电工程学院 **2025 级电气工程及自动化 3 班** 学期课表。

单文件静态网页，数据全部内嵌，断网也能打开，手机上可直接看。

## 功能

- **按周切换**：1–18 周自由翻，自动定位「本周」并高亮今天那一列
- **单双周自动过滤**：马原、大学英语的 78 节是双周课，翻到单周会自动消失
- **仅看本周有课**：一键收起当前周不上的课
- **课程详情**：点卡片看这门课全部上课周分布
- **移动端适配**：窄屏自动变成按天排列的清单
- **可直接打印**：打印样式已处理，A4 贴桌面上
